# CSS Loader Generator — Free Online Tool

**CSS Loader Generator.** Generate pure CSS spinners and loaders: rings, dots, bars, pulse and ripple. No JavaScript or GIFs. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/css-loader-generator](https://miguelacm.es/tools/css-loader-generator)

## ✨ Features

- **⚡ Six animation types:** Ring, dual ring, bouncing dots, equalizer bars, pulse and ripple.
- **🎛️ Tunable:** Color, size and duration with a live preview of the result.
- **🔒 100% private:** Generated locally, nothing is uploaded.

---

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/CssLoaderGenerator.git
cd CssLoaderGenerator
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/css-loader-generator
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/css-loader-generator
```
